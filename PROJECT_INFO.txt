🔧 OPTIMIZATION TIPS FOR PI 5
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Use streaming mode for video (lower memory)
2. Resize images to 640x480 or 1024x768
3. Process every 2nd or 3rd frame in videos
4. Close other applications to free memory
5. Use bfloat16 dtype when supported
6. Enable swap if using 4GB Pi 5
7. Consider overclocking Pi 5 for better FPS
